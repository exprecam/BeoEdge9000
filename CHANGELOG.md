# Changelog

## 2.1.0 — first public release

Public release of the widget, previously a private media widget with a different look.

- Complete visual redesign inspired by the Bang & Olufsen Beosound 9000: brushed-aluminium glass
  front, six disc bays, sliding read head, black glass display with LEDs, ribbed anthracite panel.
- Six-disc history with album covers; the read head glides to the playing disc and clamps its hub.
- Disc spinning with spin-up and wind-down inertia; **Disc Speed** setting (30–400 rpm).
- Amber standby clock (time and date) when no media is playing.
- Settings: Finish (Silver / Anthracite / Black), Glow Color (Amber / Cover Artwork), Disc Speed,
  plus the existing background, idle cover and spectrum options.
- Play / pause on the knob, previous / next keys in the display.
- Translations in 12 languages.
- Tooling: `scripts/build.py`, `scripts/check.py`, CI check.
